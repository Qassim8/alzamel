# الزامل كلين — AL ZAMIL CLEAN

موقع تعريفي لشركة تنظيف سعودية — Next.js 14 (App Router) + Tailwind CSS، عربي RTL بالكامل.
التصميم مبني على **الهوية البصرية المعتمدة** (`AL-ZAMIL-CLEAN-Approved-Identity.pdf`).

## التشغيل

```bash
npm install
npm run dev
```

**التوزيع المعتمد:** 60% أبيض / 25% كحلي / 15% أزرقيات العلامة — وهو ما يتبعه الموقع فعلياً.

**قاعدة من الهوية مطبّقة في الموقع:** لا يُستخدم النص الأبيض فوق التركواز للكتابة الصغيرة — يُعتمد الكحلي، أو الأبيض فوق الكحلي.

الألوان معرّفة في مكانين (كلاهما يجب أن يتطابق عند التعديل):

- `app/globals.css` → `:root` (للتدرّجات والظلال)
- `tailwind.config.js` → `theme.extend.colors` (قيم صريحة كي تعمل معدّلات الشفافية مثل `bg-primary/50`)

### الشعار

`components/Logo.js` يحتوي الشعار كمسارات SVG **مستخرجة حرفياً** من ملف الهوية (صفحة 02) — ليست رسماً تقريبياً.
نسخة مستقلة منه في `public/brand/mark.svg`.

- `<Logo />` — القفل الكامل (قطرة + الاسم العربي + اللاتيني). `tone="white"` فوق الخلفيات الكحلية.
- `<LogoMark />` — القطرة فقط (تُستخدم كعلامة مائية في الأقسام).

> لا تُعدّل مسارات الشعار أو ألوانها.

### الخطوط

## ⚠️ ما يحتاج تعبئة قبل النشر

### ١. الأسعار (مطلوب)

الهيكل جاهز والأرقام فارغة — عدّل `lib/data.js`:

```js
// الباقات: ضع السعر مكان null
export const PACKAGES = [
  { id: "monthly", price: "٧٥٠ ر.س", period: "شهرياً", ... },
];

// الشقق والفلل: ضع السعر مكان null
export const UNIT_PRICING = [
  { group: "الشقق", units: [{ label: "شقة غرفتين", priceFrom: "٤٥٠ ر.س" }] },
];
```

ما دام `null` يظهر تلقائياً **"عرض سعر مخصص"** و**"حسب المعاينة"** — فالموقع صالح للنشر الآن، ويتحوّل لعرض أسعار صريحة لحظة تعبئتها.

### ٢. بيانات التواصل

`COMPANY` في `lib/data.js`: الجوال، البريد، السجل التجاري، أوقات العمل.
**تأكد من `phoneIntl`** — كل أزرار واتساب في الموقع تبني روابطها منه.

### ٣. روابط السوشيال

`SOCIALS` في `components/Footer.js` — حالياً `href: "#"`.

### ٤. النطاق

استبدل `alzamil-clean.sa` في: `app/layout.js` و`app/sitemap.js` و`app/robots.js`.

### ٥. نموذج التواصل

مفتاح مجاني من https://web3forms.com → انسخ `.env.example` إلى `.env.local` وضع المفتاح في `NEXT_PUBLIC_WEB3FORMS_KEY`.

### ٦. صور الخدمات (اختياري)

كل خدمة في `SERVICES` لها حقل `image`. الخدمات التي لها صورة تظهر بصورة حقيقية، والباقي بغلاف متدرّج بألوان الهوية مع أيقونة الخدمة — وكلاهما متناسق بصرياً.
لإضافة صورة: ضعها في `public/images/` واكتب مسارها:

```js
{ id: "sofa", image: "/images/sofa.jpg", ... }
```

## إضافة خدمة جديدة

أضف عنصراً واحداً إلى `SERVICES` في `lib/data.js` — يظهر تلقائياً في صفحة الخدمات والفوتر وقائمة النموذج، وبرسالة واتساب مجهّزة باسمه.
ضع `featured: true` لإظهاره ضمن الخدمات المختارة في الصفحة الرئيسية.

## الحركة (Animations)

- `components/Reveal.js` — ظهور عند التمرير عبر `IntersectionObserver` (بلا مكتبات).
- `components/Counter.js` — عدّاد تصاعدي للأرقام.
- شريط كلمات متحرك، تكبير خفيف للصور عند المرور، وتدرّج لوني متحرك على الأزرار.

شبكتا أمان ضد بقاء المحتوى مخفياً: الإخفاء مشروط بكلاس `js` على `<html>` (بدون جافاسكربت يظهر كل شيء)، إضافة إلى مؤقّت احتياطي ٣ ثوانٍ.
كما يُحترم `prefers-reduced-motion` فتتوقف كل الحركات.
